# Test passages for Bible import

Short excerpts used only by `BibleImportTest` to check that imported Bibles work with every feature
(word studies, red letters, paragraphs, headings and footnotes are dropped from the text).
They are 31 verses per version, within each publisher's allowance for quotation without written permission
(up to 500 verses, not a complete book, and less than a quarter of the work it appears in).
